# Jaén · sierra y Renacimiento

Guía web de la Sierra de Cazorla, Segura y Las Villas, Úbeda y Baeza: sitios con horarios y precios, rutas, bares de tapeo, restaurantes, escapadas por la provincia, mapa y el tiempo.

Web: https://mueblescarrascosa.github.io/jaen/

- `index.html`: toda la guía (HTML, CSS y JavaScript en un solo fichero). Parte de la misma base que la guía de Granada.
- `sw.js`: permite usarla sin conexión. Hay que subir su versión (`jaen-vN`) en cada cambio.
- `comprobar.py`: prueba automática antes de publicar (`python comprobar.py index.html`; necesita Playwright).

Lo que cada persona marca (visitados, probados, plan) se guarda solo en su navegador.
